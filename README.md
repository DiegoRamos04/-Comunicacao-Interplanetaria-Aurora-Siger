# -Comunicacao-Interplanetaria-Aurora-Siger
Projeto acadêmico da FIAP: Análise exploratória, estruturação e defesa de dados do Núcleo Cognitivo da colônia espacial Aurora Siger. Implementado em Python utilizando Pandas para processamento de métricas operacionais, elétricas e de comunicação a partir de bases JSON.
